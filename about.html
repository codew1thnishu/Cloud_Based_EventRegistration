About the System

A simple cloud-based event management solution.

About

This Tiny Project demonstrates how a web application can use Firebase Authentication and Cloud Firestore to manage events and participant registrations.

Main Features

  • Admin authentication using Firebase Authentication
  • Event creation, editing and deletion
  • Dynamic event listing
  • Online participant registration
  • Cloud storage using Firestore
